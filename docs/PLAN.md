# 영어회화 복습장 웹앱 최종 계획

## 1. 완성된 모습
- 주소 하나(`https://ummin.github.io/english-review/`)로 누구나 접속한다.
- **구글 / 카카오 / 이메일 링크** 중 하나로 로그인하면 각자 자기 복습장을 쓴다.
- 유튜브 링크와 스크립트를 넣고, 자기가 쓰는 AI 채팅으로 카드를 정리한다.
- 앱 안 플레이어로 구간을 들으며 따라 말하고, 체크하고, 복습한다.
- 내 카드는 공유 링크나 카드 파일로 지인에게 줄 수 있다. 받은 사람은 자기 복습장에 추가해 각자 기록을 쌓는다.
- 기록은 Supabase DB에 저장되어 PC와 폰이 동기화되고 사라지지 않는다.

## 2. 구조
```
GitHub Pages (공개: 앱 코드만)         Supabase (비공개: 데이터)
┌───────────────────────────┐        ┌──────────────────────────────┐
│ Vue 3 + TypeScript + Vite │ ─────→ │ Auth: 구글 · 카카오 · 이메일    │
│ YouTube IFrame 플레이어     │        │ DB: videos · progress · settings│
│ (무료, 키 없음)             │        │ RLS: 내 데이터는 나만            │
└───────────────────────────┘        └──────────────────────────────┘
       ↑ GitHub Actions: 테스트 통과 시 자동 배포
```

| 도구 | 역할 |
|---|---|
| Vue 3 + TypeScript + Vite | 화면, 타입 검사, 빌드 |
| Vue Router (해시 주소) | 화면 이동. Pages에서 새로고침 404 방지 |
| Pinia | 상태 관리 |
| supabase-js | 로그인, DB 읽기·쓰기 |
| YouTube IFrame API | 앱 안 재생 (무료) |
| Vitest / Playwright | 로직 테스트 / 화면 테스트 (폰 폭, 라이트·다크) |

## 3. 데이터 설계

### 테이블
```
videos    id, owner_id, youtube_id, title, cards(jsonb), created_at, updated_at,
          share_id(공유 링크용, 없으면 비공유)
progress  user_id, video_id, card_id, dates(date[]), star, time_offset
settings  user_id, daily_goal
```
- `cards`는 질문과 그 아래 대답 묶음 전체를 JSON으로 담는다. 기존 Claude 복습장과 같은 구조라 편집·저장이 단순하고 이사도 그대로 된다.

### 권한 규칙 (RLS)
- `videos`, `progress`, `settings`는 `owner_id = 로그인한 사람`일 때만 읽고 쓴다.
- 공유 영상은 `share_id`를 아는 사람만 전용 함수로 "읽기"만 한다.
- 다른 계정이 내 데이터를 읽지 못하는지 테스트로 반드시 확인한다.

### 화면과 저장소 분리
화면은 "저장소 인터페이스"만 사용한다. 샘플 구현으로 화면을 먼저 확정하고, 나중에 Supabase 구현으로 교체한다.

## 4. 화면과 기능

### 기존 복습장에서 그대로 옮기는 것
- 홈: 연속일, 최근 7일, 오늘 목표 링(변경 가능), 어제 복습 배너, 영상 목록
- 문장: 전체 / 남은 문장 / 어려움 필터. 체크해도 흐리게 남고 필터를 다시 누르면 정리
- 복습: 전체(질문·대답 묶음) / 오늘 / 날짜별 + 카드 복습. "다시 볼래요"는 같은 카드로 돌아옴
- 어려움(별), 한글·영어 가리기, 시간 맞추기 ±1초
- 완료 버튼 3상태: 처음 / 오늘도 / 오늘 완료 + 작은 취소
- 디자인: 입체 버튼, 주황·파랑·초록, 라이트·다크, 하단 탭 4개(홈·문장·복습·어려움)

### 새로 생기는 것
1. **로그인**: 구글 / 카카오 / 이메일 링크, 로그아웃, 계정 표시
2. **앱 안 플레이어**
   - 위쪽 고정, 스크롤해도 따라옴 (유튜브 규정상 최소 200px 유지)
   - ▶로 해당 구간 이동·재생, 구간 끝에서 자동 정지
   - 반복, 1배속 / 0.75배속
   - 퍼가기가 막힌 영상은 유튜브로 여는 링크로 자동 전환
3. **영상 등록 (AI 채팅 방식)**
   1. 링크 + 스크립트 붙여넣기
   2. "AI용 프롬프트 복사" (스크립트가 길면 나눠서 복사)
   3. AI 답 붙여넣기 (설명이나 ``` 는 자동 무시, 끊긴 답은 이어 붙이기)
   4. 미리보기·편집 후 저장 (저장 / 버리기 버튼은 위에 고정)
4. **공유**
   - 공유 링크: "공유 켜기" → 링크 복사 → 받은 사람이 로그인 후 "내 복습장에 추가"
   - 카드 파일: `.json` 내보내기·가져오기 (체크 기록 제외)
   - 카드는 복사되어 들어가므로 원본을 고치거나 지워도 받은 사람 카드는 유지
5. **설정**: 하루 목표, 내 데이터 전체 백업 파일 받기

## 6. 직접 해야 할 일

| 시점 | 할 일 |
|---|---|
| 1번 후 | GitHub Settings → Pages → Source를 **GitHub Actions**로 |
| 5번 전 | supabase.com 가입, 프로젝트 생성(지역: 서울), 주소와 공개(anon) 키 전달 |
| 5번 중 | 제공한 테이블·RLS SQL을 Supabase SQL 편집기에서 실행 |
| 6번 | **구글**: Google Cloud Console에서 OAuth 클라이언트 생성 → Supabase 등록 |
| 6번 | **카카오**: Kakao Developers 앱 등록, 카카오 로그인 활성화, 동의 항목 설정 → Supabase 등록 |

비밀 키는 채팅에 붙이지 말고 Supabase 화면에만 직접 입력한다.

## 7. 위험과 대응

| 위험 | 대응 |
|---|---|
| 카카오 로그인의 이메일 동의 항목은 설정이 필요하고, 계정 상태에 따라 비즈 앱 전환을 요구할 수 있음 | 6번에서 확인. 이메일이 안 되면 카카오 고유 ID로 로그인하도록 설계 |
| 일부 영상은 퍼가기가 막혀 있음 | 3번에서 대상 영상부터 확인하고, 막히면 유튜브 링크로 전환 |
| 아이폰은 첫 재생에 직접 탭이 필요 | 첫 재생 안내 표시 |
| Supabase 무료 프로젝트는 장기간 미접속 시 일시정지(데이터 보존) | 매일 사용하면 해당 없음. 백업 파일로 이중 안전장치 |
| AI마다 답 형식이 다름 | 틀린 줄은 건너뛰고 읽은 개수를 알림. 확인 3·5에서 프롬프트 보정 |
| 공개 저장소 | 저장소에는 코드와 지어낸 샘플만 넣는다. 강의 카드는 Supabase에만 저장 |
| 강의 내용 공유 | 링크를 받은 사람만 볼 수 있게 하고, 공개 목록·검색은 만들지 않는다 |

## 8. 이번에 하지 않는 것
규칙 기반 자동 정리, 앱스토어 앱, 공개 카드 목록·검색, 여러 사람이 한 영상을 같이 편집하는 기능.
